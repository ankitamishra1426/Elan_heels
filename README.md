# 👠 ÉLAN Heels

A premium luxury women's heels e-commerce website inspired by modern luxury fashion brands.


---

## ✨ Features

- Premium Luxury UI
- Responsive Design
- Product Collections
- Product Details
- Wishlist
- Shopping Cart
- Authentication
- User Profile
- Checkout Flow
- Admin Dashboard
- REST API Integration

---

## 🛠 Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- Framer Motion
- Axios
- Lucide React

### Backend (Upcoming)

- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Cloudinary
- Multer
